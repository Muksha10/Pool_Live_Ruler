Keyboard Controls 🎹
Key	Function

Shift + WASD	Fast movement (15x faster)
Ctrl + Mouse	Place ball at cursor
Alt + Mouse	Smart Snap - finds and snaps to ball
+	Increase ball size
-	Decrease ball size
F1	Quick save settings
F2	Load last save
F3	Delete last save
ESC	Exit program
